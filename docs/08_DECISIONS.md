## D1. 사진·일기 중심 구상에서 3D 펫 게임 중심으로 확장

| 항목 | 내용 |
|---|---|
| 처음 기록된 문서 | 게임 기획·설계 덱 (2026-11-19)에서 게임 기획서로 전환, 통합 포트폴리오 (2026-11-20)에서 3D 펫·대화·미션 중심으로 정리 |
| 문제 | 사진 정리와 AI 일기만으로는 차별점이 약했습니다. iPhone 사진 앱이 이미 반려동물 사진을 모아 보여주고, 기획서 스스로 "기존 추억 기능으로 충분하다고 느끼는 사용자가 많을 수 있다"는 위험을 적었습니다. 별의 세계가 "실시간 게임인지, 다이어리를 감상하는 3D 정원인지"도 열린 질문이었습니다. |
| 검토한 대안 | ① 사진 정리·AI 일기 앱 유지, 3D는 부가 기능 ② 기록 + 3D 정원 수집 (기억 1개 = 추억별 1개) ③ 별의 세계를 게임플레이 중심으로 두고 기억을 대화·미션의 재료로 사용 |
| 선택 | ③ |
| 선택 이유 | 플레이어가 등록한 기억이 콘텐츠가 되어 다시 방문할 이유를 만들 수 있습니다. 기록 기능은 현실 세계에 남겨 게임의 입력이 되게 했습니다. |
| 남은 검증 | 기억 기반 미션이 실제로 재방문 이유가 되는지 (POC 3, 7일 재열람). 이전 기획의 AI 일기 초안 기능을 남길지. |

## D2. 완전한 메시 생성보다 기본 모델 개인화를 우선 검토

| 항목 | 내용 |
|---|---|
| 처음 기록된 문서 | 제품기획서 v0.1 (2026-11-07) "현재 결정: 3D 방향" |
| 문제 | 사진마다 메시를 생성하면 품질, 닮음, 리깅, 생성 비용이 매번 달라집니다. 네 발 동물은 사람용 골격(SMPL)을 쓸 수 없습니다. |
| 검토한 대안 | ① 완전 생성형 이미지 기반 3D ② 대표 체형 + 공통 리그 ③ 하이브리드 (사진 특징으로 프리셋 제안 + 수동 수정) |
| 선택 | ③ 하이브리드를 기본안으로, ①은 같은 사진으로 비교하는 실험 대상으로 유지 |
| 선택 이유 | 공통 리그로 애니메이션을 재사용할 수 있고 품질이 안정적입니다. 성공 기준이 "원본 재현"이 아니라 "게임에서 보기 좋은 닮음"이기 때문입니다. |
| 남은 검증 | 프리셋만으로 닮았다고 느끼는지 (POC 1, 5점 척도). 만족도가 낮을 때만 생성형 실험을 확대. |

## D3. 게임 상태 관리와 LLM 대사 생성 분리

| 항목 | 내용 |
|---|---|
| 처음 기록된 문서 | 통합 포트폴리오 22쪽 (포트폴리오 PDF 5쪽) (2026-11-20) |
| 문제 | LLM 출력은 매번 달라지고 실패할 수 있습니다. LLM이 퀘스트 진행이나 보상을 결정하면 진행이 막히거나 대사와 상태가 어긋날 수 있습니다. |
| 검토한 대안 | ① LLM이 대화와 퀘스트 진행을 함께 결정 ② Unity 상태 기계가 진행·완료·보상을 결정하고 LLM은 대사만 생성 |
| 선택 | ② |
| 선택 이유 | 진행 조건과 저장을 테스트 가능한 게임 로직에 두면, LLM이 실패해도 기본 대사로 미션을 끝낼 수 있습니다. |
| 남은 검증 | 대사와 퀘스트 상태가 어긋나는 사례 수 (POC 3). 네트워크 차단 상태에서 미션 완료 여부. |

## 기획 변경 내역 (문서 간 차이)

현재 기획과 이전 문서가 다른 부분입니다. 이전 문서의 내용은 기획 발전 과정으로 남겨 둡니다.

| 항목 | 제품기획서 v0.1 (11-07) | 게임 기획 덱 18장 (11-19) | 현재 (포트폴리오, 11-20) |
|---|---|---|---|
| 정의 | 추억을 기록하고 별의 세계에서 다시 경험하는 개인화 **서비스** | 내 반려동물의 추억을 심는 3D 별의 정원 (모바일 **게임**) | 3D 펫을 만들고 별의 세계에서 교감하며 모험하는 AI 기반 모바일 **게임** |
| 중심 경험 | 사진 선택 → 추억 묶기 → AI 일기 초안 | 추억 기록 + 정원 꾸미기·교감 | 3D 펫 개인화 + 대화·미션·스토리 |
| 별의 세계 이름 | 별의 세계 (시간이 멈춘 정원/마을) | 별의 정원 | 별의 세계 |
| AI 대화 | P2 이후 (RAG 대화) | 후속 후보 | 핵심 콘셉트 ② |
| 수집 단위 | — | 기억 1개 = 추억별 1개 (MemoryStar) | 추억 미션 (QuestState) |
| 플레이 루프 | — | 사진 고르기 → 추억 완성 → 정원 꾸미기 → 함께 돌아보기 | 사진·기억 등록 → 3D 펫 생성·꾸미기 → 별의 세계 진입 → 교감·미션·스토리 |
| 플랫폼 | iOS 앱 우선, Android 이후 | iOS POC → Android 검토 | 모바일 (세부 미정) |
| POC 구성 | 사진 POC → 일기 POC → 3D POC → 통합 | 기록 P0 + 3D P0 + 통합 데모 | POC 1 3D 개인화 + POC 2 AI 대화 → POC 3 추억 미션 |

## 열린 결정

- AI 일기 초안 기능을 현재 게임에 남길지
- 앱과 Unity를 합칠지(Unity as a Library), Unity 단독 앱으로 시작할지
- 먼저 공략할 사용자군
- 엔딩이 있는 스토리를 제공할지
- 대화용 LLM과 벡터 인덱스를 기기 안에 둘지, 서버에 둘지
