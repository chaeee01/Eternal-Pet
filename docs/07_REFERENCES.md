# 07. 레퍼런스

> 확인 시점: 2026-11-20. 공식 페이지와 보도자료, 논문, 공식 문서만 적었습니다.
> 게임 레퍼런스는 **공식 설명을 바탕으로 정리한 것이며, 직접 플레이한 경험에 근거한 내용이 아닙니다.**
> 외부 게임 이미지는 저장소에 넣지 않고 공식 페이지로 연결합니다.

> 참고: `besideo.com`은 마이 리틀 퍼피의 공식 사이트가 아닙니다. 별도의 AI 반려동물 추모 앱이며, 아래 2.1에 따로 정리했습니다.

**공식 설명에서 확인한 요소**

| 관점 | 내용 |
|---|---|
| 반려동물의 행동을 활용한 탐험 | 냄새 맡기, 짖기, 달리기, 점프 같은 개의 행동으로 진행한다. 행동에 한계가 있어 사람과 다른 개의 도움을 받아야 한다 (Steam). |
| 만남과 재회의 서사 | 개들의 천국에 사는 웰시 코기 '봉구'가 아빠(주인)의 냄새를 맡고 마중을 떠난다. 길에서 아직 평안을 찾지 못한 개와 사람을 만난다 (Steam, 크래프톤 보도자료). |
| 캐릭터 표현과 몰입 | 보호소에서 입양된 8살 노견이라는 구체적인 배경을 가진 캐릭터. 개발사 대표가 실제로 입양한 코기를 바탕으로 했다고 밝힘 (Steam, 크래프톤 보도자료). |

**Eternal Pet에 참고할 요소**

- 반려동물다운 행동(냄새 맡기, 짖기)을 조작과 탐험의 수단으로 쓰는 방식 → 별의 세계의 "이름 부르기", "함께 걷기" 같은 교감 행동을 미션 조건으로 쓰는 설계
- 재회를 향해 가는 서사 구조 → 추억 미션이 "그날의 장소"로 가는 짧은 여정이 되도록 구성
- 구체적인 배경을 가진 캐릭터가 주는 애착 → 플레이어가 입력한 성격과 기억이 그 역할을 하도록 설계

**Eternal Pet과의 차별점**

| 구분 | 마이 리틀 퍼피 | Eternal Pet (기획안) |
|---|---|---|
| 주인공 펫 | 정해진 캐릭터 (봉구) | 플레이어의 반려동물 사진으로 개인화한 3D 펫 |
| 대사 | 작성된 스토리 | 성격과 기억을 반영한 AI 펫 대화 |
| 이야기 | 모든 플레이어에게 같은 서사 | 개인의 추억을 바탕으로 한 미션 |
| 재회의 의미 | 사후 세계에서 주인을 마중 | 이별을 전제하지 않음. 현재 함께 사는 반려동물도 대상 |

### 1.2 Spiritfarer

| 항목 | 내용 |
|---|---|
| 공식 링크 | [thunderlotusgames.com/spiritfarer](https://thunderlotusgames.com/spiritfarer/) |
| 개발사 | Thunder Lotus |
| 플랫폼 | PC(Steam), Nintendo Switch, PlayStation, Xbox |
| 장르 | 공식 소개: "죽음에 관한 아늑한 경영 게임 (a cozy management game about dying)" |

- **참고한 요소:** 영혼들을 돌보며 함께 추억을 만들고, 작별하는 법을 배우는 구조 (공식 페이지).
- **적용 가능성:** 이별과 회상을 무겁지 않게 다루는 톤. 떠나보낸 반려동물을 기억하는 플레이어를 위한 표현의 참고.
- **차별화 방향:** Eternal Pet은 작별을 핵심 사건으로 두지 않고, 플레이어의 실제 기억을 재료로 교감을 이어가는 데 집중합니다.

| 항목 | 내용 |
|---|---|
| 공식 링크 | [Nintendo 공식 페이지 (영국)](https://www.nintendo.com/en-gb/Games/Nintendo-3DS/nintendogs-cats-Toy-Poodle-New-Friends-274534.html) |
| 개발·배급 | Nintendo |
| 플랫폼·출시 | Nintendo 3DS, 2011년 (유럽 기준 2011-03-25) |

- **참고한 요소:** 터치, 음성, 카메라로 반려동물과 교감. 주인 얼굴을 인식하는 기능, 액세서리 꾸미기 (공식 페이지).
- **적용 가능성:** 쓰다듬기·이름 부르기 같은 직접 입력에 즉시 반응하는 교감 설계, 아이템 꾸미기.
- **차별화 방향:** 정해진 견종 중에서 고르는 대신 사진으로 외형을 개인화하고, 돌봄 수치 대신 기억 기반 대화와 미션을 중심에 둡니다.
